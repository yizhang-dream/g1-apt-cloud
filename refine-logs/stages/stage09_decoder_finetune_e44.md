## 阶段 9：解码器微调 E44（2026-08-14/15，稳健负结果）

> 【层位 L2 叶子｜阶段史明细（1 阶段 = 1 文件）】↑ `HANDOFF/02_EXPERIMENT_HISTORY.md`（阶段索引）｜↓ `refine-logs/tracker/` 系列文件（L3 Run 台账）｜≈ 同层：`refine-logs/` 专题日志。

问题：0.08 悬崖是否可以通过**解冻并 RL 微调 SONIC 解码器**顶开？
`decft_policy.py`/`ppo_core.py` 让 PPO 评分梯度经 log N(a;μ,σ) 直达解码器。

| 变体 | 做法 | 结果 |
|---|---|---|
| v1 | decoder_lr 默认 + 输出正则 1.0 | 失败：dec_dw 0→46、dreg 0.5–2，输出离开官方流形；评测 0/9 全倒**含平地**（原地高速打转，σ=0.03 使梯度放大 ~1100×） |
| v2 | 小 LR + 权重锚定 + 大噪声 | 失败：约束生效（dec_dw 6–7.5）但平地评测门仍 0/3 打转——约束只推迟退化 |
| v3 | + 偏航角速度惩罚 | 失败：惩罚过强奖励崩掉（E32–34 奖励再工程泥潭复现） |
| ctrl | 冻结官方解码器对照 | **3/3 走 12.75–13m** → decft 代码路径无 bug，打转 100% 来自解码器漂移（顺带暴露 E39 z 头 partial-load 维度不匹配） |
| p（两阶段） | 先冻结训好 z（p1b 平地门 3/3、18.4m）再解冻 | 失败：解冻后 0/18 全倒含平地——消除"随机 z"混杂后结论不变 |

**E44 结论**：任何程度的解码器微调都会重新激活 SONIC 快走技能的固有转向偏置
（E31–E34），把直行破坏成打转；**冻结解码器（+router/方向 bin VAE）的直行鲁棒性
是承重墙，不是可有可无的初始化**。0.08 悬崖在本蒸馏/RL 堆栈内无法顶开（但它是
蒸馏路径边界而非解码器固有上限，见 MQ09）。
