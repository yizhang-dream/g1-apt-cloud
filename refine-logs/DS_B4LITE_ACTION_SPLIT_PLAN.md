## 0. 定位与总原则

- **授权链**：owner 09-06 五点意见——①选数据围绕迁移+保真，四类不够要加
  语义标签；②清洗分三层，执行失败≠脏数据；③先定留出规则再切片增广，并
  声明可学习表示参与情况；④首版做 100–200 条能回答问题的小集合；⑤每条
  数据最终要能回答四问（清单）。"你现在最该补的是面向论文的动作清单与
  划分协议"——本文即该交付物。
- **约束关系**：统辖 DS 线的仍是纲领，冲突条款以纲领为准；本文细化
  `DS_OFFICIAL_DATA_PLAN.md` §3 流水线的 B4-lite 节点，B3' 门判据、B4 全量
  编码、T1 切分等其余条款不变。
- **总原则（一句话）**：每选入一条数据，都要能回答"它让论文的哪个主张变
  得可检验"——不能回答的进扩展池，不进首版。
- **数据集的三项论文职责**（对应纲领 §1 主假设与 §3 候选差异主张）：①提供
  适配训练动作（部分族）；②提供留出动作族（T-fam 核心测试）；③提供能力
  边界参照（第三层清洗产物，报告绝对通过能力用）。

## 1. 动作选择标准（按论文用途，不按类目规模）

### 1.1 五维语义标签（在 walk/run/jump/dance 之上叠加）

现有四类只够验证转换与回放接口（D044 B3' 门的用途），不足以证明"跨动作
迁移"。每条候选段打五维标签：

| 维度 | 需要覆盖的差异 | 对论文的作用 |
|---|---|---|
| 移动方式 | 前进、转向、侧移、启停 | 避免只学会直线行走（对接方向偏斜风险 R3/D1） |
| 上肢动作 | 对称/非对称、缓慢/快速、小幅/大幅 | 检验适配能否保留不同上肢动作（纲领 §1：上肢改变重心与角动量，须与直接复用 SONIC 混合接口对照） |
| 身体姿态 | 直立、屈膝、躯干倾斜或转动 | 检验不同姿态下的适配 |
| 接触过程 | 双支撑、单支撑、腾空、落地 | 描述动作对地形的真实要求（决定地形任务口径） |
| 时间结构 | 稳态、减速、启动、自然连续过渡 | 支持过渡与连续执行评测（对接纲领 §8 三类过渡） |

### 1.2 首版范围与排除池

- **首版优先**：无物体接触、**动作保真指标可定义**的移动动作。
- **扩展池（不入首版）**：搬物、扶墙、大幅杂技——涉及额外接触或更强全身
  动力学约束（沿用纲领 §5 暂不纳入条款），另行验证。
- **任务语义匹配原则**：地形任务的完成口径必须与动作语义一致，否则测出的
  "保真下降"是任务设计伪影而非迁移失败。例：若数据中有"行走同时挥手"，
  它很适合检验"过坡后是否仍在挥手"；**原地舞蹈不能套用"必须向前通行"的
  任务——任务要求本身就会改变原动作**。落法：移动族沿用纲领 §7 主指标
  （完整任务成功率 = 跨过障碍、经过过渡并继续行进；站住不倒不算完成）；
  低位移/原地族的任务口径在 §6 S4 按族预注册（如存活 + 动作语义保持 +
  保真阈值，不设位移门槛）。

### 1.3 标签生成流水线（不必只靠文件名）

D044 坑②的教训：类标签临时用文件名前缀正则只是近似。正式标签走三级来源：

1. **官方 metadata 生成候选标签**：`seed_metadata_v004.parquet`（51 列，与
   142,220 CSV 精确一致，D043）+ temporal_labels 时间段标注（D043 记录
   58MB 待下）——BONES-SEED 提供动作描述、时间段标注与骨架元数据；
2. **轨迹核实**：transl 差分速度/航向统计（D040 M1 同法）核定五维标签的
   定量档位；
3. **人工抽看**：每语义族抽样渲染核看（MuJoCo offscreen 管线），确认标签
   与内容一致。

同时建立**文件名细粒度描述名 → 语义动作族映射层**（D040 M1：归一 3,788
描述类；G1 原生 CSV 同样以细粒度描述名命名），映射表入仓、带置信度。

## 2. 三层清洗协议（执行失败 ≠ 脏数据）

| 层次 | 处理内容 | 处理方式 | 记录 |
|---|---|---|---|
| **L1 数据与格式错误** | 缺失值、时间异常、单位/关节顺序/欧拉轴序错误、姿态跳变、重复文件 | 修复或隔离 | 逐段原因 |
| **L2 动作内容与适用范围** | 片段过短、需要未提供的物体、动作标签不符、缺少完整过渡 | 重标注、重切分或移出首版任务（进扩展池） | 逐段原因 |
| **L3 冻结控制器执行能力** | 平地跌倒、路径漂移、支撑期滑脚、指定动作丢失 | **保留为能力边界记录，不删除** | 失败形态 + seed 复现证据 |

- **L3 是实验结果，不等同于数据质量问题**。D044 的
  `walk_forward_grab_injured_L_leg_002__A005`（受伤步态抓腿段）是现成实例：
  离线回环 0.114 rad 健康（排除转换器伪影与抖动噪声）、Isaac 闭环 3-seed
  系统性摔倒 @≈12.7s、摔前 q 跟踪健康 = 闭环空间漂移型。它应留在**困难
  动作/能力边界集**，不能被清洗得无影无踪。
- 能力边界集是论文"绝对通过能力"报告的一部分（纲领 §3 竞争力口径：必须
  同时报告绝对通过能力，不能只与自家弱基线比较）。
- **公布纪律**：B4-lite manifest 冻结时同时公布——候选数、各层排除数与
  逐原因计数、最终覆盖范围表（§5 字段聚合）。
- **结论限定**：可用平地可执行动作构建主实验集，但结论只表述为**「底座在
  平地具备的技能能否迁移到地形」**，不外推为系统全能力（对接 §3.3 措辞
  纪律）。

## 3. 留出与划分协议（先定规则，再切片增广）

### 3.1 三种测试（分别回答不同问题）

| 测试 | 定义 | 回答的问题 | 论文地位 |
|---|---|---|---|
| **T-seg 新片段** | 同一动作族的新原始序列 | 是否记住轨迹（对同族新样本泛化） | 常规泛化检查 |
| **T-fam 新动作族** | 整族不参与适配训练 | 迁移主假设的直接检验 | **论文核心**（纲领 §5「留出整个动作族测其地形执行」） |
| **T-pair 新动作×地形组合** | 动作与地形分别见过，配对未训练 | 组合迁移 | 支撑「未见过渡条件与地形组合」主张（纲领 §3 最强站得住表述） |

### 3.2 分组键与泄漏防线

- 同一原始录制的**全部派生版本同集合**：切片、`_M` 镜像（每 take 恒配
  1:1，D040/D043）、以及未来任何增广产物（yaw 变换、时间重采样/变速）不得
  跨集合；
- **演员身份是分组键**：522 演员（D043，P50 190 段/演员）足够做演员级
  留出；
- **演员留出与动作族留出分别报告**，不把两种变化混成一个结果；T-fam 的
  留出族内部同样不得与训练族共享演员，否则"新族"混入"新演员"混淆归因。

### 3.3 可学习表示参与声明（论文措辞关键）

留出动作若参与过任何**可学习表示**的训练，"未见"主张必须限定。逐一声明
三处：

1. **自建 token VAE**（e39 双解耦线 / 后续用 B4-lite 数据训练的 VAE）：
   留出动作是否在其训练集中；
2. **归一化统计**：token mean/std 标定（D038/D044 官方 token 统计量等）
   与其他逐维统计的样本来源是否含留出动作；
3. **SONIC 官方预训练**：官方 encoder/decoder 在 611h 超集上训练
   （DS_OFFICIAL_DATA_PLAN §1），其是否见过留出动作**不可由本次划分排除**。

措辞纪律（纲领 §3 原文约束，此处落为数据集操作）：论文只能写「**地形适配
阶段未见**」的动作，不得写「我们训练的整个系统未见」；留出技能若在 SONIC
预训练中出现过，只能称「上层训练未见技能的迁移」；更强且站得住的主张 =
**未见过渡条件和地形组合**。manifest 的集合归属字段携带三处声明
（§5），保证论文措辞可逐段回查。

## 4. 首版规模与构成（B4-lite v2 定义）

- **规模**：约 **100–200 条独立原始序列**，作为工程试点规模——这是建议
  起点，**不是统计充分性的保证**；数量随后按实际覆盖调整。
- **8–12 个有明确语义的动作族**，每族包含不同演员与动作强度；预先指定
  训练族、开发验证族、最终测试族。
- 与 `DS_OFFICIAL_DATA_PLAN.md` §3 B4-lite 行（每核心类 20–30 段 + 10 过渡
  段，4 核心类时代设计）的关系：本文将"核心类"升级为"语义动作族"并叠加
  划分协议；族数扩展后 100–200 条约束不变，单族段数随之收缩（约每族
  10–25 段）。
- **过渡片段单独保留**：自然启停与连续过渡独立成段，**不把独立动作硬拼接
  成"真实过渡"**（纲领 §8 三类：不经 idle 的直接 A→B、不同进入速度、不同
  接触状态）；T1 change-point 切分（DS_OFFICIAL_DATA_PLAN §3）为过渡段
  来源，受控 36 段仅作评测（T2 口径不变）。
- **族级采样权重平衡**：按族/按段平衡采样权重，防止长行走序列在帧数上
  淹没其他动作族。
- **扩数据的依据 = 发现某个动作特征缺口**（§1.1 五维标签覆盖表暴露），
  而不是"小集合做完就把全部数据编码"——B4 全量编码的触发条件由此改写，
  规模对照（B4-lite vs B4）预注册口径维持不变。

首版候选动作族示意（S2 标签完成后按覆盖缺口定稿，owner 裁定点①）：前进
行走 / 慢走 / 快走-跑（jog 家族，M1 已证不稀缺）/ 前向跳 / 原地-韵律舞蹈
（含上肢）/ 转向行走 / 侧移（若 G1 原生不极稀）/ 启停-过渡；非对称上肢
（如挥手类）与姿态变化族为优先补位候选。

## 5. 单条数据 manifest（四问清单）

B4-lite 每段数据登记以下字段（npz 伴生 manifest.json，扩 D044 现有格式）：

| 字段 | 内容 |
|---|---|
| segment_id / 来源与版本 | CSV 相对路径 + g1.tar.gz 版本与解压校验记录（D043 逐位一致） |
| 演员与镜像关系 | 演员 ID；是否 `_M` 镜像；母 take 指针 |
| 时间范围 | 起止帧 + 原生 fps（120）+ 重采样后长度（50Hz） |
| 动作语义 | 五维标签（§1.1）+ 语义族归属 + 标签置信度（文件名/轨迹/人工三级来源） |
| 速度与转向 | v_med / v_p90 / 航向变化总量（transl 差分，D040 M1 同法） |
| 上肢与接触 | 上肢活动档位；接触过程标签 |
| 质量状态 | L1/L2/L3 三层处置结果；能力边界集标记 |
| 平地回放结果 | B3' 口径：存活步数 / 摔倒形态 / q 跟踪 MAE / path ratio / seed 数 |
| 集合归属 | train / dev / test（含 T-seg / T-fam / T-pair 角色与三表示参与声明 §3.3） |
| 排除原因 | 未入首版者必填（L1/L2 层原因或扩展池标记） |

> **B3' `completed` 口径注记（2026-09-08 评审补充声明，预注册口径不变）**：
> `completed` = 全程无摔倒 **且** 走满 steps_budget；预算**含参考播放结束后
> 的末段站姿 hold**。即该判据测的是"回放 + 末 token 站姿保持"的复合能力，
> hold 相摔倒同样计入存活失败。`fall_during_playback` 字段单列区分播放相
> 摔倒，但主判不据此放宽；boundary_set 判定（如 A005 摔在播放相）不受影响。
> 公布表读者勿把 `completed` 读成纯回放存活率。

每条数据最终要能回答四问：

1. **这条动作为什么被选中？**——语义标签 + 对论文主张的支撑点；
2. **它是否真实、完整，并能被当前链路正确解释？**——L1 结果 + 转换器
   硬校验（D044 五要点）+ 回放结果；
3. **它参与了哪些模块的训练？**——VAE / 归一化统计 / 适配训练，逐项
   是/否；
4. **测它能支持论文中的哪一项结论？**——T-seg / T-fam / T-pair / 能力
   边界参照。

- **执行期四维评价纪律**（纲领 §5/§7 落地）：每个测试动作必须**同时**评价
  地形任务完成、动作保真、原技能保持、新增训练成本，四项一起报告，不得
  只报通行成功。
- **Run 行纪律**：B4-lite 构建执行时开 **D045** 起，行只进
  `tracker/D.md`；本文协议变更 append 修订记录，不删原文。
- **owner 裁定点**：①语义动作族最终清单（S2 后提候选）；②训练/开发/测试
  族的指定与 T-fam 留出族锁定；③能力边界集收录口径（如 A005 类段入独立
  列表还是首版 manifest 内标记）。

## 7. 风险与边界

1. **标签噪声**（文件名→语义族映射错）：三级标签来源交叉 + 每族人工抽看
   ≥10%；
2. **temporal_labels 未到手**：时间段标注缺失时以整段粗标签过渡，标注
   置信度降级记录；
3. **演员×族交叉空格**（某留出族无独立演员）：调族不调规则——演员留出
   优先级高于族覆盖；
4. **B3' 平地通过 ≠ 地形可执行**：平地回放只是必要条件非充分条件（纲领
   §7 防线 1 同款），B4-lite 回放结果不预支任何地形结论；
5. **方向偏斜继承**（SMPL 镜像的横移/斜向稀缺若在 G1 原生同样成立）：
   db 轴按 D1 收窄，论文主张限定前向通行（沿用 R3）。
