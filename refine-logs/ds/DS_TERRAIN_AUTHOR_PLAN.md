## 0. 三十秒版

任务 = 纲领主假设：冻结 SONIC decoder 一个权重不动，让 G1 过**未见过的地形**，同时**保留原本要做的动作**（挥手过台阶还是挥手）。路线三步：①先判生死——decoder 到底能不能演地形剧本（D059，oracle 回放爬障段）；②造数据——回放+扰动+收割的仿真飞轮（**零演示**，全部自产）；③训作者——能力范围内尽量大的模型（目标 1B 级，跟数据产量走），在 token 层**闭环**写剧本。底层数据底座：ds_bones 132G（BONES-SEED，NVIDIA retarget G1，爬障箱 3.6k 段/522 演员）已在 lab-ts。

## 1. 任务定位与竞争格局

- WholeBodyWAM / GR00T N1.7 / 社区微调：全是冻结 SONIC + 大模型作者，但任务族是**操作链**（桌面/loco-manip），不碰地形泛化（2026-09 核查）；
- 标准地形栈：每机器人 Isaac RL + 地形课程，从零训、不冻结、无动作库概念；
- 我们的生态位 = **动捕技能库（爬障语料）+ 冻结 decoder + 作者**，三者无人同时做过；
- 论文贡献形状按纲领 §3：不是全地形跑分，是**冻结条件下的地形适配迁移 + 技能保留**，且全程可归因测量（D046–D056 判别机器复用）。

## 2. 核心认识（本计划的设计依据，全部有实验号背书）

1. decoder 是**剧本执行器**，不是命令响应器：vb 档=吸引子非设定值（D048l）、方向=z 彩票+db 粗编码（D048m/q）、标签-语义对齐脆弱（D048n/p）；
2. 时间结构值钱：真剧本回放 1.71 vs 最优静态 z 1.164（D048r 上限卡）；
3. 命令接口能活的条件 = **闭环 + 富命令**：我们 3+8 槽开环失败 vs WholeBodyWAM 56 槽闭环成功（2026-09 复核修正：命令级不必然败，静态小命令集+开环才败）；
4. 保留动作 = **最小改写约束**（纲领第 2 条）：作者是剧本编辑不是重写器，这是与通用 VLA 的分界。

## 4. 模型尺寸阶梯（owner 指令：能力范围内大一点）

- **锚点（社区实证）**：3B 底座 1.62B 可训练参数，单张 RTX 4090，bf16+adafactor+grad checkpointing，8000 步——单卡 24G 可训练上限 ≈1.5–2B；
- **v0（≤80M）**：管线验证用，lab-ts 3060 可冒烟；
- **v1（目标 1B 级）**：causal transformer 或 DiT——输入 = 地形观测（局部高度图/地形描述）+ 意图动作 token 序列 + 本体感觉历史；输出 = 64 维 FSQ token chunk（40 步）+ 辅助 z 头（两臂对照用）；**模型大小跟数据产量走**：G1 语料 <千万帧 → 降 300M 级，登记原因不硬凑；
- 训练配方：bf16 + grad ckpt + adafactor；算力纪律 = CVGL 3090 优先、4090 不足再上、**不碰 6000Ada**；单卡+梯度累积为默认，det slots>1 多卡仅在被数据量逼到时申请；
- v1 初始化自开源 backbone 的候选盘点放 G2 期间做，不预设。

## 5. 数据发动机（G1，零演示飞轮）

- **源 1**：ds_bones 爬障 3.6k 段（held-out 演员留给 G4 未见动作迁移测试）；
- **源 2**：官方语料平地动作库（保留动作约束的正负样本来源）；
- **源 3**：D058 平地收割语料（飞轮试点，已在跑）；
- **机制**：oracle 回放带状态记录（真剧本×实测状态配对）→ 初始状态抖动 + 外力推扰（DAgger 式纠偏数据，jitter_and_reset 基础设施现成）→ 作者上线后自采闭环迭代（search-then-distill 转圈）；
- **格式**：统一 (state, terrain_desc, intent_tokens, token_stream) 窗格式，兼容 D057 builder 惯例（4s 窗/50Hz/speedA 标签法沿用）。

## 6. G4 验收判据（纲领三件事的可测化）

1. **过地形**：held-out 地形组合（类型×坡度×间距网格未见格）通过率 ≥ 预注册阈值；
2. **保留动作**：意图动作的 token 保真度（改写率 ≤ 阈值）+ 人工抽查录像；不许把挥手演成走路；
3. **零该动作数据 + decoder 冻结**：全程不变（ckpt md5 锚定）；
4. 对照组：纯官方语料（无地形）作者 + 无作者 oracle 回放，三臂归因。

## 7. 风险与停线

1. tokenizer 不通（D059 ①失败）→ 全线停报 owner（替代=自研 tokenizer 另立项）；
2. G0 丙（decoder 演不了爬障）→ **纲领级收线**，非实验级；
3. 作者层方向复现（扰动纠偏训练后仍走不直）→ 负结果落账：方向问题根比接口深；
4. 数据天花板 → 降模型尺寸登记，不空转；
5. 自我指涉上限 = decoder 可达集（G0 先测的就是这个，别跳步）。
