## 0. 三十秒版

任务不变：冻结 SONIC decoder 一个权重不动，让 G1 过**未见过的地形**，同时**保留原本要做的动作**（挥手过台阶还是挥手）。v2 架构一句话：**作者端到端直出 64 维 FSQ token，输入三口（运动命令〔官方 planner 同构〕+ 意图动作 token 流 + 特权地形），一体训练、评测三轴归因**。速度命令从「我们的未解难题」重定位为「官方已证的接口能力」（planner 实测稳定 ~4 m/s）——我们照官方样子吃命令口，但不以它为卖点。数据四源（planner 命令标注生成 / ds_bones 爬障 3.4k / 官方平地库 / 闭环收割），模型三级（80M→300M→1B，升档跟数据产量走）。G0 生死判别（D059）照跑不动。

## 1. v2 重设计依据（2026-09-17 调研增量，仓内外可溯）

1. **官方 planner = 命令条件剧本作者先例**：kinematic planner（10Hz ONNX，潜空间自回归 masked token 预测，监督式非 RL）吃 target_vel/mode/movement_direction/facing_direction/height（`apt_g1/sim/planner_sonic.py:96-104`；命令域 0–6.0，vs OpenHomie 实测稳定 ~4）；底层 RL 跟踪解码器（PPO+非对称 AC，Isaac Lab 最高 21K GPU 时，survey `LITERATURE_SURVEY_DS_MANIFOLD.md:197-216`）。「冻结解码器上做命令条件 token 作者」官方已示范——本计划从发明变**再实现**，差异化照旧四条：地形域/零演示/小模型/因果测量栈；**速度可指定正式记为非卖点**。
2. **速度遵循三证据链**（可做到）：自由动作空间+速度奖励（SOLO 0.4–1.0、FastStair 0.5–2.0、APT）；冻结解码器+官方 planner（~4）；我方 token 空间自身（D048n speedA 严格单调 {0.29,0.47,1.31}、D048q 软混 0.71–1.20、D055 token 直驱 0.89、oracle 1.71）。D048 系列 0/144 的失败收口在**自建 VAE 接口+环境等宽分桶+开环**（D055：接口外 0.89 > 接口内任何受控速度），不在 decoder、不在原理。
3. **先验=软正则可活、硬端口死**（外部双印证）：SOLO 以 AMP 软正则+自由动作空间过全地形；FastStair 里 AMP 基线在楼梯 >1 m/s 趴窝。我方冻结端口是既定约束，作者必须在端口内闭环——这是本计划的存在理由。
4. **SOLO 两件可移植武器**（arXiv 2608.26583）：TA-MSE（下一状态师生分歧加进 PPO 奖励、GAE 回传=时间信用分配版蒸馏，长程 97.5% vs 逐帧 75%）→ 本计划模仿漂移**对策③**；QR（per-cell 傅里叶查询重建高程图，L1 降 3.3–4×、踏石 0–3%→96%）→ 感知阶段（G6）备档。
5. **方向轴跨栈死结**（已知最大风险）：D048m z 彩票 + D055 token 直出仍偏航摔（yaw 50–69°）——长在语料/decoder 侧。v2 姿态=随行+评测出口（§7 轴A、§9.2）。
6. **FastStair 混合形态启示**（arXiv 2601.10365）：规划器选段+RL 执行——作者不必纯端到端；本计划 v0 若 BC 生成不稳，检索+改写是登记过的降级形态（不预设）。

## 4. 作者规格明细

- **输入**：①运动命令（target_vel 标量 + movement_direction + mode + height，官方 planner 同构；工程坑沿 D033 在案：target_vel 数值非单调〔-1 哨兵≈2.5 > 显式 1.5〕，源 1 采集与评测统一 -1 哨兵约定 + mode 走 SLOW_WALK/RUN 调速路径）；②意图动作 token 流（语料段 / planner 生成剧本）；③特权地形观测（局部高程图/地形参数）；④本体感觉历史（**状态输入非决策口**，§3② 的「三口」指决策条件口）。
- **输出**：64 维 FSQ token chunk（40 步 @50Hz）。
- **训练配方**：BC 先行（四源语料 token 预测，监督式）→ RL 后续（Isaac/mjlab 地形课程 + 命令跟踪奖励）；**TA-MSE 登记=模仿漂移对策③**（①扰动回放 ②闭环微调 ③TA-MSE）；planner 生成剧本与语料段同池混训，防作者对 planner 分布 OOD。
- **算力纪律**：CVGL 3090 优先、4090 不足再上、**不碰 6000Ada**；bf16+grad ckpt+adafactor；单卡+梯度累积默认，多卡仅被数据量逼到时申请。

## 6. 数据发动机（D060，四源）

- **源 1 · planner 命令标注生成**（新，平地命令轴主源）：官方 planner 按 target_vel 扫描 × mode 产**命令-剧本对**——命令标签在数据出生时对齐，避开 D048n/p 语料重标定坑（speedA 可修但校准式必塌缩）；-1 哨兵约定；产出物抽查（D033 在案：planner 裸出 2.12 vs deploy 回路 1.0，衰减差入账）；
- **源 2 · ds_bones 爬障**：climbing box **3,402 段**（held-out 演员留 G5 未见动作迁移）；近亲池备用 step up 1,964 / obstacle 1,532 / platform 1,570 / jump over 1,218；
- **源 3 · 官方语料平地库**：BONES-SEED 288h/142,220 条（保留动作/风格底座；速度域抬升〔→~4〕在存量内可及的证据基础）；
- **源 4 · 闭环收割**：oracle 回放带状态记录 + 初始抖动 + 外力推扰（jitter_and_reset 现成）+ 作者上线后自采闭环迭代（D058 采集器已关闭〔⑨〕，此处另造）；
- **格式**：统一 (command, state, terrain_desc, intent_tokens, token_stream) 窗格式，D057 builder 惯例（4s 窗/50Hz/speedA 标签法沿用）。

## 7. 评测电池（联合为纲+三轴诊断）

- **主指标**：联合任务通过率（命令+地形+意图全口，held-out 地形组合）——与 SOLO（97.5% 穿越）/FastStair（速度-成功率带）同一语言可对话；
- **诊断轴 A · 平地命令**：速度跟踪带（对照官方 planner 实测档：deploy 回路 1.0 / planner 裸出 2.1 / 论文稳 ~4）；**方向子项**（航向误差/横漂）= ⑪ 的评测出口；
- **诊断轴 B · 地形**：mjlab/Isaac 地形 realized_ratio + 存活率，甲乙丙式判读（沿 G0-③ 口径）；
- **诊断轴 C · 保留动作**：意图 token 保真（改写距离 ≤ 阈值）+ 人工抽查录像；不许把挥手演成走路（最小改写约束的可测化）；
- 一体训练（⑤）的失败经三轴定位到轴，不设训练关卡。

## 8. G5 验收判据（纲领三件事可测化）

1. **过地形**：held-out 地形组合（类型×坡度×间距网格未见格）通过率 ≥ 预注册阈值；
2. **保留动作**：改写距离 ≤ 阈值 + 人工抽查；
3. **零该动作数据 + decoder 冻结**全程（ckpt md5 锚定）；
4. **三臂对照**：纯官方语料（无地形）作者 vs 无作者 oracle 回放 vs 全口作者，三臂归因。

## 9. 风险与停线

1. G0 丙（decoder 演不了爬障）→ **纲领级收线**，非实验级（不变）；
2. **方向轴**（⑪）：随行+评测出口——预注册合法落账=「作者层方向不响应，与 D048m/D055 跨栈证据一致」；救援不预设；
3. **两难点捆绑**（①⑤的代价，owner 确认接受）：归因依赖评测三轴；三轴全败且联合指标败 → 按轴落账，最多 2 轮调参不空转；
4. **planner 分布 OOD**：源 1 与语料段混训缓解；planner 产出物质量抽查入 D060 预注册；
5. **模仿漂移**：三对策登记（扰动回放/闭环微调/TA-MSE）；
6. 数据天花板 → 降档登记不硬凑（不变）；自我指涉上限 = decoder 可达集（G0-③ 正在测，别跳步）；
7. 编码器同源坑（v1 沿袭）：anchor ref-rel、encoder 版本勿混 low_latency。
