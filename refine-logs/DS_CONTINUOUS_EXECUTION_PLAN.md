## 1. 目标和完成定义

目标：在冻结 SONIC decoder 和现有 VAE 的前提下，让 G1 在平地稳定跟踪前进速度及零偏航角速度命令，解决超速、横漂、掉头和随训练推进出现的姿态退化。先解决0.4 m/s直走，再验证0.2/0.6 m/s及速度切换；不要求任意转向或全速度域。

成功完成必须满足本计划的平地存活、速度、方向、姿态和多训练种子验收条件。若预注册诊断预算耗尽仍失败，交付可信基线、受控比较、失败边界与成本记录，并明确目标尚未实现；不能把负结果写成攻克目标。不得用持续跑训练代替进展，也不得以穷尽所有模型和超参数作为完成条件。

接收本协议作为执行指令后，执行代理在阶段预算内自主完成代码修复、测试、既有服务器上的仿真训练/评测、结果复算和台账更新；不因一次脚本完成或一次负结果结束任务。地形适配、未见动作迁移、VAE训练、真实机器人、额外付费算力、SONIC解冻和公开发布均不属于本任务范围。

## 3. 每轮执行流程

每次接续必须先读本文件、AGENTS.md、SCRIPT_MAP、最新 tracker 和状态记录，再查 Git、远端进程/实验 ID、原始日志、实际 checkpoint 与配置身份。发现更新时增量推进，不从头重跑。

状态至少包含：阶段、当前假设、预注册判据、代码/配置/资产哈希、训练与评测种子、运行 ID/PID、输出目录、已用交互量与 GPU 时间、已完成项目、下一动作、阻塞原因和恢复条件。台账记录正式事实，状态文件只负责续接，不复制另一个版本的结论。

循环执行：核验现状 → 选择当前门的最小判别动作 → 落盘协议 → 测试 → 单个试验或评测批次 → 核查实际消费配置 → 复算原始产物 → 判定并记账 → 进入下一动作。有远端运行时先监测该运行，同时做必要的独立分析，不重复提交同一个配置。

交接不能只保存 policy.state_dict。当前 train 的 --resume 只恢复模型和迭代号，未恢复优化器、随机数、环境和调度状态，不能称为精确续训。需要分段训练时先实现并验证完整恢复；否则从同一个起点重跑有界实验，并如实记录为权重初始化的新运行。

**动机**：D049-R1 复验阴性已把「w 不动」定位到信用分配侧（合法梯度 + 执行侧 w→速度线性敏感 Q1 + kl_vb 1e-6 无学习压力）。传统处方是 D050 三件套先诊断再分支（奖励重构/课程 vs σ/熵/预算）；owner 09-12 裁量**先验注入直接干预**：不从零靠 score-function 发现「命令→档位」关联，BC 预先把 vb 头教成命令→目标软权重映射，再验 PPO 能否接住。与 D050 分支甲（奖励侧显式引导）互补不冲突；D050 号保留给诊断（①③保持候选、②作为本实验伴生插桩内置）。

**设计（单变量：对照=D049-R1 b-fix，唯一新增=发射前 BC 预热）**：
- 目标映射：`w*(cmd) = argmin_{w∈Δ²} (w·v − cmd)²`，v={0.29, 0.47, 1.31}（speedA init 档位图 D048n，**机体 vx 口径注记**：直走假设下≈净前向，方向轴差时两者分离，判读分项记录）。投影即分段线性：0.4→(0.389, 0.611, 0)、0.6→(0, 0.845, 0.155)。
- 监督损失：`L_bc = CE(softmax(vb_logits(obs)), w*(obs[67]))`（交叉熵以 w* 为目标分布，规避 log 0），**只更新 vb_logits 线性层**（encoder/z/res 头/vb_log_std 全冻结——单变量纪律：不污染共享特征分布；随机特征上 1D 命令映射的可拟合性由 G4 门验证）。
- 预热循环：训练 it 循环前插入，`--vb-bc-warmup-steps`（默认 0=关）步在线 rollout（act 正常采样、命令正常重采样 vx~U(0,0.8)），每步对当前 batch 做一次 CE 更新（独立 Adam，`--vb-bc-lr` 默认 1e-3）；预热末打命令网格 {0, 0.1, …, 0.8} 的 w(cmd) 校准曲线进 train_log（改写 obs[67] 为网格值读确定性响应，it0 响应判读锚）。

**消费者测试门 G4（发射前强制，本机 torch-cpu，G1-G3 不动照跑）**：用将上线的同一损失与「只动 vb_logits」约束，在合成 (obs, cmd) 数据上小规模拟合复现，断言：①softmax(vb_logits) 加权速度落投影容差带（全命令网格 |ŵ·v − proj_v(cmd)| ≤ 0.05）；②零更新对照臂不达标（区分学习 vs 先验偏置）。

**判读（预注册四分支）**：
- **甲（先验+维持+门改善）**：预热末 w(cmd) 分离显著（0.4 vs 0.6 的 w 距离 ≥0.5，对照 D049-R1 基线 0.0100）且 200it 不漂回 [0.36,0.31,0.32] 均匀带，联合门 ≥1 格过 → 信用分配断链被先验注入绕过成立，瓶颈 B 注入路径闭合（G-1/G-3 重开）。
