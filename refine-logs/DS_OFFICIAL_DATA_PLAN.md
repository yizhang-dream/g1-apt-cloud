## 1. 退役影响面分析（丢什么、不丢什么、怎么补）

**关键论点（退役代价比直觉小）**：本管线消耗动捕数据的只有**token VAE
（动作库）与评测材料**两处——RL 策略与地形适配模块（纲领 §1 主假设）的
训练数据由 Isaac 交互生成，不消耗动捕。退役只影响数据供给侧，不触及
主假设执行路径。

| A 线独有资产 | 原用途 | 官方数据替代 | 残余风险 |
|---|---|---|---|
| 命令标注速度（键盘档位 ground truth） | VAE vb 轴标签 | SMPL transl 50Hz 差分 = 动作自身速度（代理标注 A1） | 代理 =「实际做了什么」而非「想要什么」——对 VAE 反而更贴（要的就是可执行动作）；RL 接口 cmd→vb 映射可用 ds_smoke 命令对校准（非训练用途） |
| 方向 8bin 网格 | db 方向轴 | 类内挖转弯段 + SMPL yaw 增广 + 主张收窄 | 横移/斜向可能极稀（BONES-SEED 方向偏斜早有记录，`HUMAN_READABLE:859`）；M1 审计定量后定 db 轴去留 |
| 受控过渡段（12 对 × 3 相位，36 段） | 过渡训练材料 | **288h 连续流自然过渡切分（T1）**——非 idle 直切/变进入速度/变接触状态天然满足纲领 §8 三类 | 某些 A→B 对可能天然不存在；受控 36 段转**评测集**（T2） |
| 4 族 mode 语义（SLOW/HAPPY/RUN/JUMP 键位） | regime one-hot | 文件名类目（33 大类）作 regime；接口层粗粒度映射（双层架构不变量维持） | 类目↔deploy mode 非一一对应；regime 粒度改造与 n_vbins=3 写死坑同批处理 |
| 物理检验（官方 WBC 回路 = 可执行性闸） | 数据卫生学 | Isaac oracle 回放 B3 门（D034/D038 已证 Isaac 回放诚实） | 低 |
| held-out 族 {18,19,2} | 流形连续性检验 | 类级留出 + **演员级留出**（522 演员；纲领阶段一本就要求按演员划分） | 无（检验更强了） |

**官方数据的两个结构性优势**：①规模 ~760×（288h / 5180 万帧 vs 自采
22 分钟）；②**decoder 流形原生分布**——SONIC 自己就是用这套数据（611h
超集）训练的，官方 encoder 编码官方动捕的 token 天然落在冻结 decoder 的
流形内，而自采数据的 token 落点从未被官方保证。

**可逆性（owner-skepticism 纪律）**：自采管线资产全部在仓（驱动脚本、
键位标定、卫生学规则、D030 地形矩阵）。若 M1 审计显示官方数据在方向/
速度上有补不满的缺口，重启 A 线采集是纯执行问题（脚本现成，~1–2h 机时/
批）——退役是管线决策，不是资产销毁。

## 2. 方案空间（六个决策轴）

| 轴 | 选项 | 权衡 |
|---|---|---|
| **1 数据范围** | **O1** 分层小集合先行（每核心类 20–30 段 + 10 过渡段）／**O2** 类目主线（walk+jump+dance+run ≈ 47.5k 段全量）／**O3** 全类全量（131k 段） | O3 在 B3 通过率未知前全量编码 = 烧机时赌注；O1 单独走太慢（主假设需要多样动作库）；**O1→O2 渐进**天然构成规模对照（小集合版 vs 主线版同判据）——原双流形「规模瓶颈 vs 容量天花板」问题在官方数据内部保留，预注册两向皆硬结论 |
| **2 标签来源** | **L1** 纯代理（transl 速度/航向/类目）／**L2** 代理 + ds_smoke 校准（非训练用途）／**L3** 无监督 token 聚类找 regime | L3 研究向但绕开类目语义，列备选不作主；L2 近零成本 |
| **3 过渡材料** | **T1** 自然过渡切分为主训／**T2** 受控 36 段转评测集／T3 维持采集 | T3 违反退役指令不可行；训练要多样性、评测要可控性，T1+T2 正好分家 |
| **4 方向覆盖** | **D1** 接受偏斜 + 主张收窄（db 先砍 fwd/back 二值）／**D2** 挖掘 + yaw 增广后恢复 8bin | D1 起步、M1 定量后升 D2；横移/斜向若极稀则论文主张限定前向 |
| **5 编码算力** | **E1** 本地 3060 批量 ONNX（估 GPU 1–3h + joblib IO 并行）／E2 云 A10／E3 类内抽样率控制 | 主线全量 E1 应可承受（实测定），不行再 E2 |
| **6 自采处置** | S1 纯封存／**S2** 校准 + 探针（非训练）／S3 双流形对照臂（官方 vs 官方+自采锚） | S2 默认；S3 科学价值高但引入混源，owner 裁定 |

**推荐组合**：**O1→O2 渐进 + L2 + T1/T2 + D1→D2 + E1(+E3) + S2**。

## 4. 门与判据（承接纲领 §4/§7）

1. B3' 类级存活 ≥95%（不过门不入集，逐类独立判定）；
2. 质检四件：lattice 违例 = 0；oracle 回环 MAE 与官方 token 同级；接触
   真实性抽检（D035 协议）；q 跟踪 MAE 记录；
3. **按原始序列与演员划分** train/val（相邻帧不得跨集）；
4. 失败片段保留原因记录（纲领阶段一要求）；
5. 规模对照预注册：B4-lite vs B4 同判据（G1 三件），两向皆硬结论，
   不预设赢家。

## 5. 风险清单

1. **R1（最高）SMPL 模式 token↔decoder 兼容性未知**——B2-s 第一闸。
   预注：SMPL transl 是世界系坐标，锚定语义大概率复现 D036 的 apply_delta
   坑，逆向布局时直接按 ref-rel 语义设计（f=0 identity sanity 内置）。
   Fallback 链：①shape/betas 归一与锚定修正 → ②SMPL→G1 自研重定向
   （骨架拟合 + 形状匹配，~1 周工程）→ ③owner HF token 重试
   bones-studio/seed 的 G1 格式直取。
2. **R2 run 类稀缺**（758 段，文件名初分口径）：G3 已降辅助指标（纲领
   §9）；M1 测速度直方图后定量，若不足则 RUN 主张降级或增广。
3. **R3 方向偏斜**：D1 起步；横移/斜向挖不出则 db 轴砍为 fwd/back，
   论文主张限定前向通行（纲领 §3 措辞纪律约束表述）。
4. **R4 过渡切分假阳性**（change-point 切到稳态段/切碎过渡）：B3 抽检 +
   人工抽看 10 条。
5. **R5 类目噪声**（文件名初分）：M1 内容抽验修正，regime 标签带置信度。
6. **R6 编码 IO**（131k joblib pkl）：并行读取 + 分批落盘；实测瓶颈再议
   云端 E2。
