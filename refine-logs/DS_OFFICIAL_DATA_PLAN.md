## 1. 退役影响面分析（丢什么、不丢什么、怎么补）

**关键论点（退役代价比直觉小）**：本管线消耗动捕数据的只有**token VAE
（动作库）与评测材料**两处——RL 策略与地形适配模块（纲领 §1 主假设）的
训练数据由 Isaac 交互生成，不消耗动捕。退役只影响数据供给侧，不触及
主假设执行路径。

| A 线独有资产 | 原用途 | 官方数据替代 | 残余风险 |
|---|---|---|---|
| 命令标注速度（键盘档位 ground truth） | VAE vb 轴标签 | SMPL transl 50Hz 差分 = 动作自身速度（代理标注 A1） | 代理 =「实际做了什么」而非「想要什么」——对 VAE 反而更贴（要的就是可执行动作）；RL 接口 cmd→vb 映射可用 ds_smoke 命令对校准（非训练用途） |
| 方向 8bin 网格 | db 方向轴 | 类内挖转弯段 + SMPL yaw 增广 + 主张收窄 | 横移/斜向可能极稀（BONES-SEED 方向偏斜早有记录，`HUMAN_READABLE:859`）；M1 审计定量后定 db 轴去留 |
| 受控过渡段（12 对 × 3 相位，36 段） | 过渡训练材料 | **288h 连续流自然过渡切分（T1）**——非 idle 直切/变进入速度/变接触状态天然满足纲领 §8 三类 | 某些 A→B 对可能天然不存在；受控 36 段转**评测集**（T2） |
| 4 族 mode 语义（SLOW/HAPPY/RUN/JUMP 键位） | regime one-hot | 文件名类目（33 大类）作 regime；接口层粗粒度映射（双层架构不变量维持） | 类目↔deploy mode 非一一对应；regime 粒度改造与 n_vbins=3 写死坑同批处理 |
| 物理检验（官方 WBC 回路 = 可执行性闸） | 数据卫生学 | Isaac oracle 回放 B3 门（D034/D038 已证 Isaac 回放诚实） | 低 |
| held-out 族 {18,19,2} | 流形连续性检验 | 类级留出 + **演员级留出**（522 演员；纲领阶段一本就要求按演员划分） | 无（检验更强了） |

**官方数据的两个结构性优势**：①规模 ~760×（288h / 5180 万帧 vs 自采
22 分钟）；②**decoder 流形原生分布**——SONIC 自己就是用这套数据（611h
超集）训练的，官方 encoder 编码官方动捕的 token 天然落在冻结 decoder 的
流形内，而自采数据的 token 落点从未被官方保证。

**可逆性（owner-skepticism 纪律）**：自采管线资产全部在仓（驱动脚本、
键位标定、卫生学规则、D030 地形矩阵）。若 M1 审计显示官方数据在方向/
速度上有补不满的缺口，重启 A 线采集是纯执行问题（脚本现成，~1–2h 机时/
批）——退役是管线决策，不是资产销毁。

### 3.1 B2-s 实验协议（D040，2026-09-05c 预注册——第一个实验）

**目的**：打通「SMPL 镜像数据 → smpl 模式 obs → 冻结 encoder → token →
冻结 decoder → Isaac 物理闭环」全链路，关闭风险 R1（全计划最高风险项）。
PASS = 解锁 M1/B3'/B4 全部下游；FAIL = 走 fallback 链，不动主线下游。

**素材**（三件，全在服务器，无前置等待）：
1. `sample_data/smpl_filtered` 官方样例（布局规范参照）；
2. 131,455 段镜像中抽 1–2 段 walk 类（~8s 中等时长；验证批量读取路径与
   真实数据代表性）；
3. B1 的 6 个 g1 格式 pkl——若其中存在与 SMPL 样例同动作的双格式样本，
   加做**配对 token 对照**（同一运动双模编码，token 距离 = 布局正确性的
   最强证据）。

**步骤**：

1. **布局逆向（~0.5d）**：observation_config.yaml 全读 + encoder ONNX
   输入签名探针（输入名/维度/窗口）+ 新脚本 `encode_smpl_smoke.py`
   （登记 SCRIPT_MAP，镜像 `encode_bones_smoke.py` 结构，D036 g1 同法）。
   四个预注册陷阱：①SMPL y-up vs 本栈 z-up；②ref-rel 锚定直接内置
   （f=0 identity 作 sanity，不等失败再修）；③50Hz 假设核验（打点间隔
   直方图）；④axis-angle 约定与关节序。
2. **分布级判据（~1h）**：S1/S2（下表）。
3. **Isaac 冒烟（~2h）**：复用 `replay_bones_tokens_isaac.py`（canonical
   零改动，吃 tokens npy）2 seed × 40s；参考轨迹 = SMPL transl 累计
   路径。sim_app.close() 挂死坑已有 daemon + 超时 + os._exit 处置（D037）。
4. **判读落账**：tracker/D.md D040 行 + 本节回写判定。
